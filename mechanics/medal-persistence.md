十二枚星座奖牌各有独立的跨存档收集进度，进度会跨角色线、字母线和周目保留。在 `PATH A: END` 之后，游戏会检查十二枚奖牌是否都已正式记录。

::: {.callout-important}
## 三个不同阶段

奖牌收集包含三个彼此不同的层次：

::: {.pw-process-list}

1. **剧情发现：**奖牌在故事中出现，或被角色找到；
2. **正式记录：**游戏将对应奖牌计入跨存档收集进度；
3. **最终检定：**Path A 结局重新检查十二枚奖牌的收集记录。

:::

只有第二步完成后，该奖牌才会永久计入最终检定所使用的收集状态。
:::

## 奖牌进度如何保存

十二枚星座奖牌各有独立的跨存档收集记录。推进到正式记录某枚奖牌的剧情后，后续流程就会将其视为已收集。

b0.85 没有用于清空十二枚奖牌收集记录的正常游戏内选项；普通剧情分支也不会撤销已记录的奖牌。

读取普通剧情存档会恢复故事状态，但会保留已取得的奖牌。因此，可以在不同角色线和周目中分别收集，最后完成 Path A 时一并计入。

取得奖牌后，建议让当前场景完整结束，并建立一个普通存档，再切换流程或退出游戏。

## 找到奖牌不一定已经完成解锁

部分奖牌会先在故事中出现，但之后才被正式计入收集进度。

最明显的例子是：

- **水瓶座：**D4 在树篱迷宫中被找到，但要到 D16 的 A/B 奖牌盘点场景才正式记录；
- **金牛座：**D7 在巨型南瓜下方被找到，同样要到 D16 才正式记录。

因此，玩家可能清楚记得自己已经看过这两枚奖牌，但它们尚未计入跨存档收集进度。

相对而言，双鱼座、巨蟹座和摩羯座会在各自 D9 角色线场景中正式记录，即使其准确星座身份要到之后才得到确认。

具体发现位置和正式记录时间见[十二枚奖牌收集指南](../collectibles/medals.md)。

## 为什么同一枚奖牌会被多次记录

同一枚奖牌可以在不同剧情分支或后续盘点中再次记录。例如，双鱼座、巨蟹座和摩羯座在对应角色线的 D9 场景中就已取得，D16 的 Path A/B 盘点会再次确认这些记录。

处女座和射手座也会在多个互斥的关系结局分支中重复记录：

- 任意一个有效的 Path A 结局分支都会取得处女座；
- 任意一个有效的 Path B 结局分支都会取得射手座。

::: {.pw-key-rule}

玩家不需要为了同一枚奖牌完成六种关系结局。

:::

## 最终十二枚奖牌检定如何工作

在 `PATH A: END` 之后，游戏会逐一核对十二枚奖牌是否已正式记录。检定结束后：

- 少于十二枚：当前 Path A 结局后的流程结束，不进入 Path P；
- 十二枚全部已记录：剧情继续进入 Path P 最终流程。

::: {.callout-note}
## 检定只在 Path A 结局后运行

游戏不会持续监控玩家何时取得第十二枚奖牌。

如果第一次完成 Path A 时奖牌尚未收齐，之后在其他流程中补齐缺失奖牌，并不会自动重新打开最终剧情。玩家必须再次完成 Path A，让十二枚奖牌检定重新运行。
:::

## 后记与奖牌进度

后记中的十二个星座背景资料与 Path P 最终检定使用同一份跨存档奖牌收集进度。

不过，当前游戏会话中新取得的奖牌，可能要到重启游戏后才会在后记中显示解锁。完整的访问条件和刷新行为见[后记解锁索引](../collectibles/compendium.md)。

## 游戏不会重置哪些奖牌数据

b0.85 没有清除全部十二枚奖牌收集记录的正常游戏内选项。

D1 的隐藏密码 `THE END` 会重置若干结局记录，包括真结局记录和 Path A—G 的结局记录，但**不会**清除十二枚星座奖牌的收集状态。

删除普通剧情存档同样不会撤销奖牌记录。只有清除保存跨存档进度的全部游戏用户数据、未完整迁移用户数据，或更换设备时遗漏相关数据，才可能导致奖牌进度丢失。

## 奖牌进度排错

如果最终检定仍然报告奖牌不完整，请依次检查：

1. 每枚奖牌是否真正推进到游戏正式记录它的剧情，而不只是看过首次发现场景；
2. 重启游戏后，后记的星座背景资料中是否仍有锁定条目；
3. 十二枚奖牌全部正式记录后，是否重新完成了一次 Path A；
4. 如果在不同设备之间迁移进度，跨存档收集数据是否与普通存档一起完整转移。

最快收集顺序和十二枚奖牌的位置见[十二枚奖牌收集指南](../collectibles/medals.md)。
