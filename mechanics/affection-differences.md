《Password》b0.85 的角色互动会改变部分对话、亲密场景和关系结果。

具体日期与菜单见[角色选择指南](affection.md#完整加点清单)。本页按场景整理前置选择和剧情结果，方便回看不同**差分**。

::: {.callout-important}
## 读表要点

- 表中的“亲密路线”“克制路线”等均指角色指南中的完整选择方案；只在方案上做指定改动，其余选择保持一致。
- 默认 D1 输入 `Chase`、D3 不输入 `THE LOVERS`。已使用关系彩蛋、改变 D5 电影或 D7 家庭话题的旧存档，不宜直接套用菜单结果。
- 回看应从改动发生前的存档开始。D9 早晨安慰先于当天同伴菜单，之后的选择不能倒改已经看到的差分。
- 差分还需要实际到达对应角色线与日期；D15—D16 的方案适用于 Path A/B。部分场景另需金库成功，具体要求见下表。
:::
