## Routes and Paths

### Are character Routes and lettered Paths the same thing?

No. The D4 partner choice sets the character Route, while later choices, password checks, and survival outcomes determine the lettered Path. The two systems continue alongside each other.

See [Route and Path Overview](route-overview.md) and [Lettered Path System](path-system.md).

### How do I reach Path P?

Complete Path A after all twelve medals have been recorded. Medal progress carries across saves and playthroughs, but the final check runs only after the Path A ending.

If you finished Path A too early, collect the missing medals and complete it again. See [Twelve-Medal Collection Guide](../collectibles/medals.md).

### Why does my save display a different Path from the choice I made?

The save slot shows the Path confirmed by the story when that save was created. Some choices do not update the display until their outcome is revealed later.

The Sal Route can also display `Path C` briefly after a failed D10 check even though its Route-specific exception keeps the story on the shared Path A/B side. See [Lettered Path System](path-system.md).

### Why can the save-slot survival icons disagree with the story?

A save slot keeps the survival icons from the moment it is created or overwritten, so older slots do not update as the player continues elsewhere. Only Dean, Tyson, Orlando, Sal, Roswell, and Hoss are shown on D1–D6; Benson appears on D7–D9, and Oswin appears from D10 onward.

Most main-story deaths update the icons after Dave confirms what happened, so Oswin temporarily appearing alive on D10 can be a normal narrative delay. A few endings in b0.85 also fail to update the icons correctly: saves made during the character-specific Bad Endings, late Path F, or one Path E ending may still show dead characters as alive.

This affects the save display only, not the story, lettered Path, or ending.

## Passwords

### What format do Vault passwords use?

Vault input is not case-sensitive, and leading or trailing spaces are removed. Spelling, punctuation, internal spaces, and the correct day still matter.

The first password group also depends on the current character Route. For progressive clues, see [Tiered Password Hints](password-hints.md).

### Why can the Sal D10 or Tyson D17 check fail without ending the run?

Both Routes have later story events that prevent the usual disaster, but the failed check is not treated as a success and its successful warning content is still missed.

See [Lettered Path System](path-system.md) for the full consequences.

## Medals and Persistent Progress

### Do I need to collect all twelve medals in one playthrough?

No. Medals accumulate across saves and playthroughs. Multiple character Routes are required because four medals are Route-exclusive.

See [Twelve-Medal Collection Guide](../collectibles/medals.md).

### Why did I find a medal in the story, but it still appears missing?

Some medals appear before the game records them. Aquarius and Taurus, for example, are not added to the collection until the D16 inventory scene.

If a Lore entry is still locked, try restarting the game first so the Compendium can refresh. See [Medal Persistence and Final Check](../mechanics/medal-persistence.md).

### Will deleting normal save slots remove my medals?

No. Medal progress is stored separately from ordinary save slots. Loading or deleting a normal story save does not undo medals that have already been recorded.

Deleting all game data or moving to another device may still remove them. See [Medal Persistence and Final Check](../mechanics/medal-persistence.md).

## Gallery, Affection, and Compendium

### How do I locate a missing Gallery CG?

Use the [CG Gallery Completion Index](../collectibles/gallery.md) to search the 72 Memories and 28 Trauma entries by Memories/Trauma tab, row and column, scene label, date/Path, story clue, or character category.

Not every story image appears in the Gallery, and the displayed completion number may require a restart to refresh.

### Does affection determine whether I can complete the game?

No. Affection does not determine the lettered Path, password success, survival, medals, or Path P.

It changes dialogue, intimate options, some CGs, and the D19 relationship outcome. See [Affection System and Point Guide](../mechanics/affection.md).

### Why is a Compendium entry still locked?

Try restarting the game first so the Compendium can display any entries you just unlocked.

If it remains locked, check the entry's requirement in [Compendium Unlock Index](../collectibles/compendium.md). For an Epilogue, make sure the previous Replay reached its ending instead of using **End Replay** early.

## Interface and Version

### Why does the character on the main menu change or disappear?

The main menu reflects the character Route and Path in the newest save. If that save was made before a character Route was confirmed, the menu shows Dave; Path E uses an empty background.

Some late Path A scenes can also change the menu character temporarily. Continue the story and make a new save to restore the appropriate display.

### Why does my game not match this guide?

The main guide covers Password b0.85, with separate archives for b0.7 and the differences between the two builds. If Routes, password scenes, or CG locations differ substantially, check your game version and download source.

## Still Stuck?

You’re welcome to get in touch if you’re stuck. To help me understand what happened, include:

1. the game version and current day;
2. the character Route and Path shown in the relevant save;
3. whether the relevant D10 or D17 check succeeded;
4. the exact medal, Cast File, Lore entry, or Additional Scene that is missing; for a Gallery CG, include its Memories/Trauma tab, row and column, and scene label if known.

Restart once before reporting a Gallery or Compendium display problem. For an Additional Scene, also confirm that the preceding Replay reached its ending.
