如果旧攻略中的线路说明与 b0.85 对不上，可以先在这里确认它是否描述了 b0.7 的旧分支。

这里记录会影响正常剧情、坏结局，或容易让旧攻略误导当前玩家的线路变化。密码、回放和更广泛的剧情改写见各自的档案页。

::: {.callout-warning}
## 仅供历史参考

不应把本页当作 b0.85 的当前通关流程。当前结构见[剧情线路总览](../guide/route-overview.md)与[字母线系统](../guide/path-system.md)。
:::

## 两个版本共有的整体结构

D4 的**角色线**与之后的**字母线**之间的区别，在 b0.7 中已经存在。b0.85 保留了 A–G 与 Path P 的大部分核心结构。

两版之间需要特别留意的是：

- 已被移除的分支；
- 旧密码对失败时间线的影响；
- 容易让旧攻略误导当前玩家的路线相关机制。

## D6 离开宅邸分支

b0.7 在 D6 宅邸流程后段曾有一个正常游玩时可以选择的菜单：**Stay.**／**Leave.**

选择 **Stay.** 会继续进入 D7；选择 **Leave.** 会直接进入 `BAD END: OZ`，本周目到此结束。

b0.85 已删除正常游玩中的 D6 离开宅邸菜单，以及对应的坏结局。

::: {.d6-result-table .table-responsive .table-scroll-compact}
| 版本 | D6 结果 |
|---|---|
| b0.7 | `Stay.` 继续；`Leave.` 进入 `BAD END: OZ` |
| b0.85 | 正常流程中不再存在该选择和对应结局 |
:::

## D7 替代输入与 D8 结果

b0.7 在 D7 接受的两个旧替代输入，都不能让玩家继续通过 D8。

因此，两者的路线结果都是：

```text
旧替代输入被接受
→ 显示预警场景
→ 进入 D8 失败时间线
→ BAD END: BENSON
```

它们不会形成额外的字母线，只会改变进入同一主要坏结局之前看到的内容。

两个输入的具体作用、预警图片和旧版提示结构见[旧版本密码档案](legacy-passwords.md)。

::: {.callout-note}
## 两个不同的 “Reveal Oz”

旧版 D7 失败时间线中也可能出现是否揭露 Oswin 的选择，但它和正常 D8 用于字母线判断的 **Reveal Oz** 不是同一个分支。

坏结局中的版本不会继承正常流程的揭露结果，也不会决定 Path A 或 Path B。
:::

## D10 之后的字母线变化与 Path P

b0.85 保留了 b0.7 的大部分字母线结构。

b0.7 与 b0.85 都已经包含以下核心结构：

- D10 后，剧情会进入 Path A/B 或 Path C/D 一侧；
- 后续角色生死结果仍可能改变字母线；
- Path E 包含不止一种全员死亡的结果；
- 后段存在 Path F/G 分流；
- Path A 结局后检查十二枚奖牌，并在满足条件时进入 Path P。

Path P 在 b0.7 中已经存在，并不是 b0.85 新增的路线。

两个版本中的核心转移都是：

```text
PATH A: END
→ 检查十二枚奖牌的跨存档收集记录
→ 十二枚全部取得
→ 剧情进入最终 Path P 流程
```

b0.85 在后续 Path P 中新增了独立输入，并加入明确的真结局跨存档完成记录。相关变化见[b0.85 版本主要变化](b085-changes.md)。

游戏没有显示正式的 `PATH P: END` 标题，也没有给出字母 `P` 的正式全称。剧情中提到的“主时间线”（prime timeline）使 `P = Prime` 成为很合理的解释，但它不是官方显示的名称。

## 不会改变字母线的旧机制

下列机制发生在线路剧情内部，但本身不会改变字母线：

::: {.table-responsive .table-scroll-medium}
| 旧机制 | 对剧情的影响 | 主要档案 |
|---|---|---|
| D8 Oswin 自由文字问答 | 会改变之后的部分对白，但不决定角色线、字母线、奖牌或结局 | [旧版本机制档案](legacy-mechanics.md) |
| D11 可选金库 | 会改变实验室与之后的部分文本，但不会改变角色线或字母线 | [旧版本密码档案](legacy-passwords.md) |
| Path A 首次流程 | 两段特殊剧情只在跨存档记录中的首次流程播放；b0.85 后来加入追加场景回放 | [旧版本机制档案](legacy-mechanics.md) |
| D11 注射选择 | 让玩家决定是否及由谁接受注射，并记录不同的选择结果，可能影响局部对白；不改变角色线、字母线、奖牌或结局 | [旧版本机制档案](legacy-mechanics.md) |
:::

Dean 相关互动改写以及 D19 关系门槛变化，不会改变字母线结构。具体变化见[b0.85 版本主要变化](b085-changes.md)。
