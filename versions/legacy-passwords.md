b0.7 有两套已无法在 b0.85 正常流程中使用的密码机制：

- b0.7 在 D7 可接受的三个金库输入；
- D11 的可选 `METEMPSYCHOSIS` 金库流程。

::: {.callout-warning}
## 不适用于 b0.85

`PEACEKEEPER` 和 `ARBITER` 已不能作为 b0.85 的 D7 输入；D11 可选金库也无法再从正常剧情进入或完成。

当前版本的密码提示见[密码分级提示](../guide/password-hints.md)。
:::

## b0.7 的 D7 三个可接受输入

b0.7 的金库在 D7 会接受三个不同的单词。三者都能够通过输入检定、播放成功反馈，并进入各自的预警场景。

但它们对第二天主线的作用并不相同。

::: {.table-responsive .table-scroll-medium}
| D7 输入 | b0.7 中的剧情作用 | 立即显示的预警 | 主线结果 |
|---|---|---|---|
| `PEACEKEEPER` | 可接受但不推进的替代输入 | Orlando 中枪 | 无法继续通过 D8 |
| `ARBITER` | 可接受但不推进的替代输入 | Dean 与 Tyson 抢夺手枪 | 无法继续通过 D8 |
| 当前 D7 答案 | 可以推进主线 | Benson 死亡预警 | 满足继续通过 D8 的条件 |
:::

输入任意一个旧替代词，都会进入 Benson 的坏结局时间线；只有当前答案能让玩家继续通过 D8。

## 旧版提示结构如何运作

b0.7 的 D7 解谜比当前版本更加迂回和困难。

普通 D7 失败会进入一段坏结局，并在同一流程中提供两个旧替代输入的线索。玩家随后可以直接输入 `PEACEKEEPER` 或 `ARBITER` 中的任意一个。

两个替代输入最终会汇合到同一段后续调查流程。该公共分支再提供真正主线答案的线索。

实际顺序是：

```text
普通 D7 失败
→ 同时获得两个旧替代输入的线索

任意一个旧替代输入
→ 进入公共调查分支
→ 获得主线答案的线索
```

旧攻略可能会按照推荐发现顺序排列三个单词，但游戏其实并不强制这个顺序，你甚至可以直接输入正确密码。

## Trauma（创伤）CG 与画廊解锁

三个 D7 输入会立即显示不同的预警画面：

::: {.trauma-warning-table .table-responsive}
| 输入 | 显示的预警画面 |
|---|---|
| `PEACEKEEPER` | Orlando 中枪 |
| `ARBITER` | Dean 与 Tyson 抢夺手枪 |
| 当前 D7 答案 | Benson 死亡预警 |
:::

正常游玩时，只要实际显示相应图片，就会解锁对应的画廊项目。

因此，b0.7 的两个旧替代输入曾提供快速显示 Orlando 和 Dean/Tyson 两张创伤 CG 的方法。b0.85 不再接受这两个单词，所以这条捷径已经失效。

当前版本的 D8 强制坏结局仍会在正常失败流程中显示旧版的相关创伤 CG。

当前画廊结构见[CG 画廊查漏索引](../collectibles/gallery.md)。

## D11 可选金库

b0.7 还包含一个非强制的 D11 金库输入：`METEMPSYCHOSIS`。

它与四个主要密码检定不同，不是继续主线所必需的密码，而是用于开启另一组实验室文本和后续条件对白的隐藏分支。

### 何时出现

玩家首次完整经历对应的 Oswin 存活 D11 实验室流程后，游戏会跨存档记录这段进度。之后再次进入符合条件的 A/B 侧 D11 流程、且该次流程满足另一项进入条件时，才可能看到额外选择：`Visit the Vault. / Stay here.`

选择 `Visit the Vault.` 会打开密码输入；选择 `Stay here.` 则直接继续剧情。

因为入口依赖跨存档状态，所以该解锁会在不同存档和角色线之间共享。单纯选择 **New Game（新游戏）** 不会恢复第一次进入该段剧情时的状态。

### 提示与成功效果

这个单词会在此前的实验室剧情中直接出现。

成功输入后，游戏只在当前周目记住已完成这次可选输入；该状态不会跨存档共享。

它会改变 D11 实验室段落及之后若干条件对白，不影响角色线、字母线、奖牌或最终结局。

## b0.85 中的 D11 旧内容

b0.85 仍会在剧情中提到这个单词，也保留少量与 `METEMPSYCHOSIS` 有关的条件对白，但正常 D11 剧情已不会打开对应的金库输入，也不会出现成功场景。

这些内容只是旧版留下的剧情痕迹，不是隐藏在当前版本中的可用密码。正常开始的 b0.85 周目会使用未完成该旧输入时的对白。

## Path P 新输入

b0.7 在 Path P 后段没有当前版本的独立文字输入。

b0.85 在原有 Path A 结局、十二枚奖牌检查以及进入 Path P 之后，新增了一次强制输入。

当前提示见[密码分级提示](../guide/password-hints.md)，更完整的版本变化背景见[b0.85 版本主要变化](b085-changes.md)。
