想从旧攻略切换到 b0.85，可以先从这里查看会直接影响游玩和收集的主要变化。旧密码、旧机制和旧线路另有独立档案。

::: {.callout-important}
## 比较范围

以下内容只比较 **b0.7 与 b0.85**，不能直接套用到所有更早版本。重点包括正常剧情入口、玩家选择、密码、跨存档解锁、后记、画廊、回放和较明显的剧情互动变化。
:::

## 主要变化一览

::: {.table-responsive}
| 领域 | b0.85 的主要变化 |
|---|---|
| 后记 | 新增角色档案、追加场景与背景资料界面 |
| 追加内容 | 新增七段按顺序解锁的后日谈 |
| 旧线路分支 | 删除 D6 离开宅邸的坏结局 |
| 密码系统 | 移除两个 D7 旧替代输入和完整 D11 可选金库流程 |
| D8 互动 | 用固定对白替代 Oswin 自由文字问答 |
| Dean 相关剧情 | 将多段依赖菜单的互动改写为固定流程 |
| Dean 关系判定 | 修改 D19 门槛，并删除旧中间区间的玩家确认 |
| Path P | 新增强制输入与明确的真结局跨存档完成记录 |
| 画廊 | 槽位从 104 减少到 100 |
| CG | 重绘两张 Tyson CG，并删除四张旧 Dean 成人 CG |
:::

## b0.85 后记

b0.85 新增了可从主菜单打开的后记，包含三个栏目：

- **CAST FILES（角色档案）**
- **ADDITIONAL SCENES（追加场景）**
- **LORE（背景资料）**

b0.7 正常游玩中没有与当前后记对等的功能。

### 背景资料与奖牌状态

背景资料栏目的十二个星座条目，会分别读取十二枚奖牌对应的跨存档状态。这使玩家可以在尝试 Path P 前，通过后记直接判断还有哪些奖牌背景资料没有解锁。

具体条件见：

- [后记解锁索引](../collectibles/compendium.md)
- [十二枚奖牌收集指南](../collectibles/medals.md)

### 追加场景

b0.85 为 Path A 第一次完整流程中的两个片段增加了回放入口：

- `Dave's Demise`
- `Roswell's Attempt`

两项会在 Path A 后段的首次完整流程结束后一起解锁。两段剧情本身早已存在，b0.85 新增的是独立回放入口。

首次流程与回放范围见[旧版本机制档案](legacy-mechanics.md)。

## 七段后日谈

b0.85 在追加场景中新增七段后日谈。

第一段会在真结局完成后解锁，之后每完成一段再解锁下一段，形成固定的回放链。这些后日谈需要从后记的追加场景中逐段打开。

当前顺序与解锁状态见[后记解锁索引](../collectibles/compendium.md)。

## 已删除或替换的旧机制

### D6 离开宅邸

b0.7 在 D6 后段允许玩家选择：`Stay. / Leave.`

选择 `Leave.` 会直接进入 `BAD END: OZ`，本周目到此结束。b0.85 则删除了正常游玩中的选择菜单和对应坏结局。

详见[旧版本线路档案](legacy-routes.md)。

### D7 旧替代输入

b0.7 的 D7 金库还会正式接受 `PEACEKEEPER` 和 `ARBITER`，社区一般把这俩密码称作“假密码”。两者都会进入独立预警场景，但都不能让玩家继续通过 D8。

b0.85 已不再接受这两个输入，当前答案成为唯一可以推进 D7 主线的输入。

详见[旧版本密码档案](legacy-passwords.md)。

### D8 Oswin 问答

b0.7 有一段可重复输入的自由文字问答，玩家可以自行向 Oswin 提问，并由旧关键词系统匹配回应。

b0.85 删除了输入循环和关键词引擎，改为固定剧情对白。少量旧话题仍会影响相关对白，但当前版本不再提供自由输入界面。

详见[旧版本机制档案](legacy-mechanics.md)。

### D11 可选金库

b0.7 在之后符合条件的 A/B 侧流程中，可以开放一个非强制 D11 金库入口。

成功输入 `METEMPSYCHOSIS` 会改变实验室和之后若干条件对白，但不会改变角色线、字母线或结局。

b0.85 删除了正常入口和对应的成功场景，只留下旧单词和部分相关对白。

详见[旧版本密码档案](legacy-passwords.md)。

### D11 注射选择

b0.7 的 Oswin 存活实验室剧情，还存在一次三选一决定。旧版会区分这三种选择，之后的局部对白可能因此不同，但不影响角色线、字母线、奖牌或结局。

b0.85 将它改为固定流程：Oswin 从背后给 Dave 注射，之后再说明注射物其实是生理盐水。玩家不再作出上述选择，也不再记录上述不同的选择结果。

详见[旧版本机制档案](legacy-mechanics.md)。

## Dean 与前中期互动重写

b0.7 的多段 Dean 剧情提供了可选对话和行动。b0.85 保留了剧情背景，将这些互动改为固定对白和事件顺序。

### D3 早餐：Dean 或 Tyson

在 D4 正式选择角色线之前，b0.7 会让玩家选择早餐时坐在谁旁边：`Dean / Tyson`

选择 Tyson 会进入一段独立且篇幅较长的宅邸探索剧情。

b0.85 删除该菜单和 Tyson 分支，固定进入 Dean 的宅邸介绍流程。

### D4—D10 的 Dean 互动

主要变化包括：

- **D4：** Dean 与 Sal 冲突中的玩家选择，以及 Dean 线的急救分支被删除；
- **D5：** 初次见面回忆从多个小选择改为线性叙述；
- **D6：** 蘑菇问答与迷路后的等待／寻找选择被删除；
- **D9：** 亲吻／转移话题菜单被删除；
- **D10：** 可循环询问四名嫌疑人的调查菜单被固定对白替代。

这些改动减少了可选角色信息和玩家控制，也改变了部分 Dean 好感点的获得方式。这些改写不影响 A–G 的分流结构。

### D19 关系判定

Dean 的 D19 关系判定变化如下：

::: {.d19-result-table .table-responsive .table-scroll-compact}
| 版本 | D19 结果 |
|---|---|
| b0.7 | Dean 好感度 ≥ 20：自动建立关系；Dean 好感度 10–19：玩家自行接受或拒绝；Dean 好感度 < 10：拒绝 |
| b0.85 | Dean 好感度 ≥ 10：自动建立关系；Dean 好感度 < 10：拒绝 |
:::

新版降低了自动恋爱的门槛，也取消了原先 10–19 点时的确认选项。

## Path P 的新增内容

Path P 的核心入口结构在 b0.7 中已经存在：

```text
PATH A: END
→ 检查十二枚奖牌的跨存档收集记录
→ 十二枚全部取得
→ 进入 Path P 最终流程
```

b0.85 保留该结构，并在 Path P 后段加入新内容。

### 强制最终输入

b0.85 在 Path P 中新增一次独立自由文字输入。答案会在此前对白中直接给出定义，错误输入会循环返回输入框。

b0.7 在同一阶段没有对应输入。

当前提示见[密码分级提示](../guide/password-hints.md)。

### 金库键盘操作者变化

b0.7 中，由 Florencia 操作金库键盘，之后 Oswin 再进一步打开金库。

b0.85 中，Dave 完成新增输入，并亲自操作键盘打开金库。

### 真结局跨存档完成记录

b0.85 在最终结尾附近跨存档记录 Path P／真结局已完成。这项真结局完成记录用于后记和后日谈解锁链。

游戏中没有正式显示 `PATH P: END` 标题，也没有把字母 `P` 展开为某个完整单词。剧情中的“主时间线”（prime timeline）使 `P = Prime` 成为合理推测，但不是游戏正式显示的名称。

## 画廊槽位：104 减少到 100

b0.7 的画廊共有 104 个槽位，b0.85 则有 100 个。

数量减少来自以下四个槽位变化：

::: {.gallery-registration-change-table .table-responsive .table-scroll-compact}
| 画廊变化 | 槽位变化 |
|---|---:|
| 一张旧 Dean 画廊图片从 Dean 分类移除 | −1 |
| D24 Dave 夜间寻路图片 1 从 Dave 分类移除，仍保留在 Misc | −1 个重复槽位 |
| D24 Dave 夜间寻路图片 2 从 Dave 分类移除，仍保留在 Misc | −1 个重复槽位 |
| D24 Dave 夜间寻路图片 3 从 Dave 分类移除，仍保留在 Misc | −1 个重复槽位 |
| **合计** | **−4** |
:::

三张手电筒图片保留在 Misc（其他）分类中，Dave 分类下的重复按钮被移除。

这张旧 Dean 图片不在 b0.85 的画廊中，正常剧情也不会显示。

当前 100 格结构见[CG 画廊查漏索引](../collectibles/gallery.md)。

## CG 变化

### 两张 Tyson CG 重绘

Tyson 驾车与 Tyson 观影这两张 CG 在 b0.7 与 b0.85 之间被完整重绘。

新版改变了整体构图、人物位置、镜头距离、背景处理和线稿与上色方式。其中驾车 CG 会出现在若干 D5/D6 坏结局后续场景；观影 CG 位于 Tyson 线的 D6。

### 四张旧 Dean 成人 CG

b0.7 的 D7 和 D9 正常剧情曾显示四张旧 Dean 成人 CG。b0.85 不再显示这些 CG，对应图片也已从游戏中移除。

尽管这些图片在 b0.7 的正常剧情中使用，它们在两个版本中都没有计入画廊总数。

## 存档界面

b0.7 已经使用角色线对应的存档槽颜色与角色头像。

b0.85 的存活状态显示有所变化：

- b0.7 使用通用状态框；
- b0.85 改为每名角色独立的存活／死亡像素图标。

存档槽头像仍然对应 D4 选择的角色线。

## 其他变化

### Tyson 的 `Stripes` 称呼

b0.85 中，Tyson 更常用 `Stripes` 称呼 Dave，这个昵称来自他身上的条纹。

### D1 `THE END` 输入

D1 彩蛋输入 `THE END` 在两个版本中都会退出游戏。

b0.85 会先清除以下完成记录，再退出游戏：

- 真结局完成记录；
- Path A–G 对应的跨存档结局完成记录。

b0.7 会直接退出，不会先清除这些记录。

完整使用说明见[彩蛋与隐藏输入](../extras/easter-eggs.md)。

## 如何识别旧版攻略

如果一份攻略要求玩家：

- D3 早餐选择 Dean 或 Tyson；
- D6 离开宅邸；
- D7 输入 `PEACEKEEPER` 或 `ARBITER`；
- D8 自由向 Oswin 输入问题；
- D11 再次进入金库并输入 `METEMPSYCHOSIS`；
- D11 选择谁接受注射；
- 在 Dean 好感度为 10–19 时自行决定是否与 Dean 建立关系；
- 解锁一个 104 格画廊；

那么它很可能描述的是 b0.7，而不是 b0.85。当前路线、密码、后记和收集要求请以 b0.85 页面为准。
