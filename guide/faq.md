## 角色线与字母线

### 角色线和字母线是同一回事吗？

不是。D4 的搭档选择决定角色线；之后的剧情选择、密码检定和角色生死状态决定字母线。两套系统会同时持续存在，但作用不同。

详见[剧情线路总览](route-overview.md)和[字母线系统](path-system.md)。

### 如何进入 Path P？

在游戏已经记录全部十二枚奖牌后，再完成一次 Path A。奖牌进度会跨存档和周目保留，但最终奖牌检定只会在 Path A 主结局之后执行。

如果过早完成了 Path A，可以先取得缺少的奖牌，再重新完成 Path A。详见[十二枚奖牌收集指南](../collectibles/medals.md)。

### 为什么存档显示的字母线与我的选择不一致？

存档槽显示的是创建该存档时，剧情已经确认的字母线。有些选择的结果要到后续剧情揭示时，存档显示才会更新。

Sal 线在 D10 放弃密码检定后，也可能暂时显示 `Path C`，但该角色线的特殊豁免仍会让剧情留在共同的 Path A/B 一侧。

详见[字母线系统](path-system.md)。

### 为什么存档槽的角色存活图标有时与剧情不一致？

存档槽会保留创建或覆盖存档时的角色存活图标，之后继续游玩不会让旧存档自动更新。D1—D6 只显示 Dean、Tyson、Orlando、Sal、Roswell 和 Hoss；D7—D9 加入 Benson；D10 起才显示 Oswin。

多数主线死亡会在 Dave 确认发生了什么以后才更新图标，所以 Oswin 在 D10 暂时显示存活，可能只是正常的叙事延迟。b0.85 也有几处确定的显示错误：在角色个人坏结局、Path F 后段，以及一条 Path E 结局中保存时，部分已经死亡的角色仍可能显示为存活。

这些情况只会让存档图标显示错，不会影响实际剧情、字母线或结局。

## 密码

### 金库密码有什么输入格式要求？

密码输入不区分大小写，首尾空格会被自动去除；但拼写、标点、单词内部空格和输入日期仍必须正确。

第一组关键密码还取决于当前角色线。需要逐级线索时，见[密码分级提示](password-hints.md)。

### 为什么 Sal 线的 D10 或 Tyson 线的 D17 检定失败后，剧情仍能继续？

这两条角色线都有特殊保护机制，可以阻止密码失败通常造成的后续灾难和字母线分流。

但**检定失败不会被当作成功**，成功分支中的警告内容和部分收集内容仍然会错过。完整后果见[字母线系统](path-system.md)。

## 奖牌与持久进度

### 十二枚奖牌必须在同一个周目中收齐吗？

不需要。奖牌会跨存档和周目累计。由于其中四枚只会在特定角色线取得，因此完成全部收集必然需要多个角色线。

详见[十二枚奖牌收集指南](../collectibles/medals.md)。

### 为什么剧情中已经发现奖牌，收集状态仍然显示缺失？

部分奖牌在剧情中出现后，不会立刻计入收集。例如水瓶座和金牛座要到 D16 的奖牌盘点场景才正式记录。

如果根据锁定的背景资料判断奖牌缺失，建议先重启游戏。后记有时不会在当前会话立即刷新解锁状态。详见[奖牌持久化与最终检定](../mechanics/medal-persistence.md)。

### 删除普通存档会清除奖牌吗？

不会。十二枚奖牌的进度与普通剧情存档分开保存。读取或删除普通存档，不会撤销已经正式记录的奖牌。

但清除全部游戏数据，或迁移到其他设备时没有完整保留用户数据，仍可能导致记录丢失。详见[奖牌持久化与最终检定](../mechanics/medal-persistence.md)。

## 画廊、好感度与后记

### 如何定位画廊中缺失的 CG？

使用[CG 画廊查漏索引](../collectibles/gallery.md)，可以按 Memories／Trauma 页签、行列、场景名称、日期／Path、剧情线索或角色分类检索 72 个 Memories（回忆）条目和 28 个 Trauma（创伤）条目。

并非所有剧情图片都会出现在画廊中；画廊显示的完成数量也可能需要重启游戏后才刷新。

### 好感度会决定能否通关吗？

不会。好感度不决定字母线、密码是否成功、角色存活、奖牌收集或 Path P。

它主要影响对话、亲密选项、部分 CG 和 D19 的关系结果。详见[好感度机制与加点](../mechanics/affection.md)。

### 为什么后记条目仍然锁定？

建议先重启游戏，让后记刷新本次游玩中刚取得的解锁记录。

如果重启后仍然锁定，请在[后记解锁索引](../collectibles/compendium.md)中核对该条目的要求。对于后日谈，还要确认上一段回放已经播放到结尾，而不是中途使用 **End Replay（结束回放）** 退出。

## 界面与版本

### 为什么主菜单角色会改变或消失？

主菜单会读取最新存档中的角色线和字母线。如果最新存档还没有确定角色线，主菜单会显示 Dave；Path E 则使用空背景。Path A 后期的部分场景也可能暂时改变主菜单角色，继续推进并建立新存档后便会恢复相应显示。

### 为什么游戏流程与本站描述不一致？

本站只记录 Password b0.85 和 b0.7 的流程。如果路线、密码场景或 CG 位置存在明显差异，请先检查游戏版本和下载来源；网上其他为旧版本编写的资料可能不适用于 b0.85。

## 仍然无法解决？

欢迎在评论区提问，也可以通过其他方式联系我。提问时，建议附上：

1. 游戏版本和当前日期；
2. 相关存档显示的角色线与字母线；
3. D10 或 D17 的相关检定是否成功；
4. 缺失项目的准确名称，例如奖牌、角色档案、背景资料或追加场景；如果是画廊 CG，请提供 Memories／Trauma 页签、行列以及已知的场景名称。

报告画廊或后记显示问题前，请先重启一次游戏。对于追加场景，还需确认前一段回放已经完整播放到结尾。
