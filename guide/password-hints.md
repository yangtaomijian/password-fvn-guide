《Password》的核心机制之一，是把不同时间线中获得的信息带回更早的节点。大部分密码需要先经历坏结局，在坏结局的对话文本中获取对应提示，再通过 **Resonate?** 返回密码检定点；少部分密码则会在输入前的剧情中直接给出线索。

b0.85 中共有四组会显著影响主线走向的关键密码，输入时间分别位于：

1. D4／D6，具体日期取决于当前角色线；
2. D7；
3. D10；
4. D17。

此外，Path P 的最终流程中还有一个相对简单的独立密码。D1 和 D3 存在可选输入；D2 虽然允许尝试输入，但当天没有可被接受的密码。

::: {.callout-important}
## 使用原则

本站默认只提供分级提示，不直接公开关键密码；Path P 的三级提示除外，展开后会显示完整密码。

建议先阅读一级提示；仍然无法找到答案时，再依次展开二级和三级提示。三级提示中的 `_` 代表一个被隐藏的字母。

本页四组关键密码和 Path P 密码均为单个英文单词。输入不区分大小写，但拼写必须正确。
:::

## 一号关键密码组

**输入时间：**

- Roswell 线：D4 下午；
- 其他角色线：D6 早晨。

六条角色线分别对应一个密码。只有输入当前角色线对应的单词，才能获得避免该角色早期失败所需的警告。

输入其他角色的有效密码则会显示与该角色有关的警告画面，但不会保护当前角色线中的搭档。

<details>
<summary><strong>一级提示</strong></summary>

每条角色线最明确的密码线索，都出现在对应角色的早期坏结局中。

这一组密码的设计逻辑是：玩家先从失败时间线中获得信息，再通过 **Resonate?** 返回此前的密码检定。
</details>

<details>
<summary><strong>二级提示</strong></summary>

注意失败剧情中被反复提到、异常强调，或者以全大写形式出现的英文单词。

这些词通常与该角色死亡或遭遇危险的直接原因有关。

Tyson 线出现信件时，需要选择 **Open it.**；选择 **Ignore it.** 会跳过明确写出的密码线索。
</details>

<details>
<summary><strong>三级提示：字母结构</strong></summary>

- Dean：`d _ _ _ h c _ p`
- Tyson：`s _ l _ d _ r _ t y`
- Roswell：`d _ s c _ v _ r y`
- Orlando：`s _ n t _ n c _`
- Hoss：`h _ r _ i s m`
- Sal：`d r _ _ m _ r`
</details>

::: {.callout-note}
Roswell 线中，输入正确密码只会获得警告，并不会自动救下 Roswell。之后仍需在对应剧情中作出正确选择。
:::

## 二号关键密码

**输入时间：**D7 傍晚

b0.85 中只有一个密码会在这里被接受。

<details>
<summary><strong>一级提示</strong></summary>

让密码检定失败并继续进入 Benson 的坏结局。

最明确的线索出现在围绕 Benson 死亡展开的几段对话中。之后可通过 **Resonate?** 返回 D7 金库。
</details>

<details>
<summary><strong>二级提示</strong></summary>

连接这两层含义的是同一个单词。
</details>

<details>
<summary><strong>三级提示</strong></summary>

这个词描述的是背弃一个信任自己的人。

**字母结构：**`b _ t r _ y _ l`
</details>

::: {.callout-note}
两个旧候选词在 b0.85 中都不会被接受为密码。剧情仍会提到其中一些旧线索，旧版本中的具体作用见[旧版本密码档案](../versions/legacy-passwords.md)。
:::

### Sal 线的特殊情况

Sal 线在这次密码检定中选择放弃，不会因此进入常规的 Path C/D 剧情。Dave 此前对 Sal 睡眠问题的介入会阻止这一分支。

收集画廊 CG 时仍需正确输入密码：成功分支会显示 Sal 的金库 CG，并同时显示一张归入其他角色分类的相关图像。Sal 的其他画廊内容则通过角色线正常推进获得，不依赖这次检定。

### Tyson 线的特殊情况

Tyson 线即使没有正确完成这次密码检定，也不会最终转入 Path F 或 Path G。

D18 会揭示高频声音的来源，Tyson 随后改在 Dave 的房间睡觉，从而避免 D19 的灾难。

这一保护不要求额外好感度、恋爱状态、特定角色存活或附加选择。完整分支逻辑见[字母线系统](path-system.md)。

## Path P 密码

Path P 的最终流程中包含一个独立密码。它不属于普通的按日期金库系统，线索会在输入框出现前直接给出。

输入错误后，流程会自动返回同一提示，不需要通过坏结局或 **Resonate?** 重试。

<details>
<summary><strong>一级提示</strong></summary>

仔细阅读 Thanatos 在键盘输入前说出的内容。
</details>

<details id="final-path-p-tier-2-hint">
<summary><strong>二级提示</strong></summary>

这个词表示把某人**神化**，或把凡人提升到神圣地位的过程。

无需从其他字母线或坏结局中寻找信息。
</details>

<details id="final-path-p-tier-3-hint">
<summary><strong>三级提示</strong></summary>

完整密码：`APOTHEOSIS`。
</details>

## 可选输入与旧版内容

早期金库中还存在一些不影响正常通关的输入：

- D1 有一个隐藏彩蛋输入；
- D2 允许玩家输入文字，但当天没有任何答案会被接受；
- D3 有一个可选彩蛋输入，成功后会提高六名角色的好感度；
- 一些旧密码词仍会在 b0.85 剧情中出现，但已不能作为密码使用；
- D11 剧情中会展示并解释一个单词，但它在 b0.85 中不是可用密码。

这些内容都不属于四组会改变路线的关键密码。其他彩蛋、特殊回应和相关细节见[彩蛋与隐藏输入](../extras/easter-eggs.md)。

## 重试机制

普通密码输入错误后，不会立刻出现 **Resonate?**。

- D3 和 D6 使用 **Try Another Password**；
- D4、D7、D10 和 D17 使用 **Try Again**；
- 对应的退出选项是 **Give up**；
- **Resonate?** 只会在部分坏结局或字母线终点出现，并将玩家送回更早的密码检定；
- Path P 的最终密码输入错误后会自动重复，不提供退出菜单。

## 仍然无法解决？

建议依次检查：

1. 当前游戏版本是否确实为 b0.85；
2. 是否参考了只适用于 b0.7 或更早版本的旧攻略；
3. 拼写是否完全正确；大小写不影响识别，输入前后的空格也会被自动去除；
4. 是否在正确日期输入；
5. 一号密码组中，是否使用了当前角色线对应的单词；
6. 是否把失败时间线中才会出现的线索，误认为首次尝试前就应出现的提示。

如果游戏流程与本页描述仍然不一致，排查时应同时记录当前角色线、日期、存档显示的字母线，以及最近一次重要选择。
